# Bounded routing comparisons

These sanitized copies preserve the 2026-11-03
[six-task synthetic comparison](synthetic/README.md) and the
[two-task repository comparison](repo-tasks/README.md), including prompts,
oracles, candidate diffs and recorded results. Session and thread identifiers
have been replaced with placeholders; they are not required to assess the
recorded outcomes. The original artifacts remain host-persistent and
non-authoritative.

The synthetic result validator passes on the retained copy. As a negative
control, changing a recorded correctness flag caused it to fail. The small,
unequal-tooling samples establish bounded feasibility, not model rankings,
provider-side model identity, subscription allocation or invoices. The local
worker-fast [clerical pilot](../2026-11-03-routing-local-clerical/README.md)
provides a separate, equally bounded observation.
